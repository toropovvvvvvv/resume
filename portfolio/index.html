01 Next.js · React · TypeScript

Система управления персоналом

Корпоративная HR-платформа полного цикла: оргструктура, сотрудники, роли и доступы, публикации, кадровый документооборот, проекты, задачи, тестирование и аттестация.

  • Сделал конструктор динамических форм: поля и таблицы настраиваются под тип документа, новые документы подключаются без переписывания UI
  • Закрывал клиентские сценарии целиком - от экранов оргструктуры и КЭДО до прохождения тестов и аттестации
  • Настроил работу с API через Orval, авторизацию на Keycloak и общие конвенции проекта, включая правила для AI-агентов
  • Покрывал ключевые сценарии unit-тестами на Vitest, чтобы регрессии ловить до релиза, а не на пользователях

B2B-сервис для подготовки налоговой отчётности: крупные формы, документы, электронная подпись, просмотр деклараций и многостраничная печать.

Подход

Как я обычно встраиваюсь в команду
01

Беру блок целиком

От уточнения требования и оценки до релиза. Не оставляю «хвосты» между аналитикой, дизайном и продакшеном.

02

Сначала границы, потом скорость

FSD, UI Kit и понятные контракты. Быстро - это когда новый сценарий ложится в уже собранную систему, а не ломает её.

03

AI ускоряет, ответственность моя

Использую агентов для черновика и рефакторинга. Code review, архитектуру и граничные случаи оставляю за собой.
